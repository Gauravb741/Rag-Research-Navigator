## Decision-recording rule

A decision is added only after the user explicitly selects an option. Routine implementation choices and ordinary bug fixes are not recorded here. After the user authorized autonomous engineering, implementation-stage decisions are recorded as engineering decisions rather than raised as additional approval gates.
